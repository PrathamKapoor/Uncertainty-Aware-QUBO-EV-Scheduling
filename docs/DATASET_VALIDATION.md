# Public charging-transactions dataset: validation

Source: Baek, Lee and Kim, [Scientific Data 11, 262 (2024)](https://doi.org/10.1038/s41597-024-02942-9); [Figshare data, version 1](https://doi.org/10.6084/m9.figshare.22495141.v1), CC BY 4.0 as stated in the data paper. Download `https://ndownloader.figshare.com/files/39952252` to `data/ChargingRecords.csv`; SHA-256 is `d541259bed55e2a9bc3413756954e7a059b50f9c9031f1dfc6ec87cbf3afd358`. The raw download is locally ignored by Git. Run `python -m experiments.public_dataset data/ChargingRecords.csv`.

The downloaded CSV contains 72,856 rows and 13 columns; all columns have zero null entries. This differs from the paper's 16-column description, so the actual file schema governs this analysis. `StartDatetime` and `EndDatetime` describe connection and disconnection; `Demand` is delivered energy, not requested energy. Declared departure, requested energy and their decision-time timestamps are unavailable. Charger location is a category, not a shared electrical site identifier. No historical multi-EV site reconstruction is claimed.

The parser excludes 547 records with missing/unparseable timestamps or nonpositive connection duration and 41 calibration sessions ending at or after the split, leaving 72,268. The latter exclusion prevents using durations not yet known at the cutoff. Thirteen fully duplicate rows were observed and retained; sensitivity to duplicates remains untested. Starts span 2021-09-30 17:14 through 2022-09-30 23:11. Timestamps lack a verified timezone and are treated as naive local time for chronological grouping; no timezone conversion is claimed. The fixed split is July 1, 2022: 50,185 calibration and 22,083 evaluation records. This is exploratory; the same dataset has been inspected, and repeated users and chargers remain correlated.

The experiment imposes an assumed 30-minute nominal availability, 1 kW charging power, 0.25 kWh target, 15-minute slots, 1 kW capacity and synthetic tariffs. It applies actual connection durations as counterfactual availability, not as measured outcomes of the simulated schedule. The baseline's nominal deadline is assumed, not a user declaration. The scenario and buffer models use only calibration durations. These assumptions restrict the conclusions substantially.
