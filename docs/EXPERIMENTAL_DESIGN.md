# Experimental design: public-duration stress test

The fixed 30-minute, two-slot, single-EV synthetic case is evaluated against the 2022-07-01 onward connection durations from the public CSV. Earlier valid records calibrate eight equal-count duration-shift groups and the 80%, 90%, and 95% linear-interpolated quantiles. F0 uses the nominal horizon; F1 minimizes the empirical-frequency scenario-average objective, with independent capacity slack per scenario; buffer methods minimize the same toy objective subject to the conservative window. Evaluation uses the same actual durations and physical decoder for every method. Energy requests are assumed and never derived from post-session delivered energy.

This experiment is exploratory, with no claim of independent preregistration. A 2,000-replicate paired calendar-day bootstrap is a sensitivity analysis for the 90% buffer versus F0; it does not address users or chargers repeated across different days. The independent-session interval is retained only as a diagnostic. The three buffer levels are exploratory and their intervals are not multiple-comparison adjusted; only the 90% comparison is reported with an interval. QAOA runs on F0 and the 90% buffer use one seed. No F2, hindsight F3, physical multi-EV capacity sweep, or F1 QAOA run is claimed.
